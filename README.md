# vibe-knowledge-video

> 知识分享动画视频制作智能体 Skill —— 没有真人说话声音，用动画、字幕、文字图解和背景音乐讲透知识。

`vibe-knowledge-video` 是一个面向 AI Agent 的 Skill 包（Vibe Coding 场景），用于把任意知识主题做成"科普风"或"参考驱动的黑金风格"动画视频。它不依赖真人配音，而是通过 **逐帧动画 + 字幕独立讲解 + 原创文字图解 + 背景音乐** 完成信息传达，并自带一套严谨的"资料核查 → 文案 → 配图 → 分镜 → 预览 → 直出成片"质量闭环。

---

## 它能做什么

- **参考分析**：读取用户提供的本地参考视频 / 截图 / 步骤，分析画幅、节奏、字体、配色、字幕位置、图解与音乐变化。
- **资料核查**：查询原始文献与官方资料，标注 8–10 个关键节点及来源，绝不编造历史、照片或规则。
- **文案与字幕**：生成"提问 → 类比 → 机制 → 转折 → 意义"结构的独立字幕与文案。
- **原创图解**：用参与方 / 连接 / 反馈回路 / 变量对照等图解"讲机制"，而非用装饰粒子糊弄。
- **分镜设计**：输出带时间轴、字幕、动作、转场与音乐节奏的分镜脚本。
- **动画渲染**：基于 HyperFrames + GSAP 生成可重复渲染的 HTML 动画，支持截图验收。
- **配乐**：支持提取用户指定参考视频的**原配乐音轨**（需本地文件），默认不新增任何说话声。
- **成片质检**：用 ffprobe `/ media.py` 核对分辨率、帧率、时长、音轨，解码抽帧检查黑屏、裁切、溢出与闪跳。

## 安装使用

只需将 `vibe-knowledge-video/` 放入 Agent 的 skills 目录即可启用（隐式调用，`openai.yaml` 中 `allow_implicit_invocation: true`）。

**触发方式**：给出主题、本地参考视频或制作步骤截图，并表达想要"知识分享动画视频"即可。参考提示词：

> 用 vibe-knowledge-video 按参考风格制作知识分享视频，保留字幕、动态图解和音乐，不加真人说话声。

**运行环境**：`script/media.py` 依赖 Python 标准库 + FFmpeg/FFprobe（默认在 PATH 查找，也可用 `--tools-dir <工程/node_modules>` 指定）。渲染建议安装 `hyperframes gsap ffmpeg-static ffprobe-static`。

## 六步制作流程

| 步骤 | 名称 | 产出 | 关键约束 |
|------|------|------|----------|
| 1 | 搜集 | `文章.md` | 原始文献/官方资料，8–10 关键节点并注来源，不编造 |
| 2 | 编排 | `文案.md` | 提问→类比→机制→转折→意义，单屏字幕 ≤20 汉字 |
| 3 | 找图 | `找图.md` | 列出所需图片、来源、使用条件与取得状态 |
| 4 | 定样式与分镜 | `分镜.md` | 沿用用户选择或出 ≤3 张样图；记录时间轴与音乐节奏 |
| 5 | 检查预览 | 约 10s 样片 MP4 | 真实字幕/图解/音乐；解码抽帧 + 试听修复问题 |
| 6 | 直出全片 | 全片 MP4 | 默认 H.264 + AAC；验收所有镜头与配乐接点 |

**产出默认为横屏 1920×1080 / 30fps / 约两分钟**（用户指定则依用户）。

## 媒体助手 `media.py`

```text
# 探测视频媒体信息（流、宽度、高度、帧率、编码等）
python scripts/media.py --tools-dir <工程/node_modules> probe <参考.mp4>

# 生成 12 帧联系表（取样分析，不代表连续观看）
python scripts/media.py --tools-dir <工程/node_modules> contact <参考.mp4> --output <联系表.jpg>

# 提取第一条音轨为 WAV（不去除说话声）
python scripts/media.py --tools-dir <工程/node_modules> audio <参考.mp4> --output <音乐.wav>

# 检查成片：分辨率/帧率/时长/编码/是否含音轨
python scripts/media.py --tools-dir <工程/node_modules> check <成片.mp4> --width 1920 --height 1080 --fps 30 --duration 10 --require-audio
```

> 输出已存在时会拒绝覆盖，需要更新请加 `--overwrite`。

## 设计理念与亮点

- **"没有真人声音"≠"没有讲解"**：讲解由字幕与文字图解独立承担，信息不依赖语音。
- **图解讲机制，禁止装饰替代**：粒子、网格只是氛围，真正的解释来自参与者、连接、反馈回路与对照。
- **尊重原创与来源**：借鉴参考的视觉语言而非复制作者署名/水印；素材未取得不得谎称已使用。
- **先样片后全片**：先出 10 秒样片并抽帧验收，确认无误再扩展直出全片，避免返工。
- **参数检查 ≠ 画面检查**：分辨率/帧率合规不代表画面正确，必须解码抽帧与试听把关。
