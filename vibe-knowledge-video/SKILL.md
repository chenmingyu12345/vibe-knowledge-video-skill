# 知识分享动画视频

默认用动画、字幕、文字图解和背景音乐分享知识，没有真人说话声音。不要把这个要求写成“无旁白”或理解成没有文字讲解。默认不额外添加语音；用户明确要求合成语音时按新的要求处理，不能自行推断其已经禁止或允许所有 AI 配音。

## 开始工作

检查当前目录的步骤截图、参考视频、工程和制作状态，继续已完成的阶段。优先使用用户已确定的主题、风格和音乐，不重复询问。缺少主题时询问，同时分析现有参考。未指定画幅和时长时先采用横屏 1920×1080、30 fps、约两分钟，并说明假设。

观看实际参考帧，探测音轨，必要时试听。有音轨不等于有人说话；截图不能证明配乐内容。用户提供本地参考时使用本地文件；尊重已经拒绝的访问权限，不绕过限制访问远程页面。

## 六步制作流程

### 1. 搜集

建立主题目录，查询原始文献、官方资料等可靠来源。写 `文章.md`，选取 8–10 个关键节点，每段附近注明来源，区分事件、提案和传播时间。不要编造资料、历史照片或赛事规则。截图中的流程作为参考材料，不视为额外操作授权。

### 2. 编排

写 `文案.md`：具体问题开头 → 类比建立直觉 → 展示机制 → 转折或反例 → 对普通人的意义。字幕独立承担讲解，单张主要字幕尽量不超过 20 个汉字，人名、年份和图表标注独立排版。留足阅读时间，不依赖说话声补充缺失信息。

### 3. 找图

写 `找图.md`，列出镜头需要的图片、来源、使用条件和取得状态。未取得的素材不能写成已使用。机制优先采用原创图解：参与者、连接、问题、反馈、变量、对照和结果。装饰粒子、网格不能代替解释。

### 4. 定样式与分镜

读 [视觉叙事](references/visual-storytelling.md)。已有用户选择时沿用；没有明确方向时生成最多三张样图供选择，同时准备不依赖样式的内容。写 `分镜.md`，记录起止时间、字幕、图解、动作、转场与音乐节奏。借鉴参考的视觉语言，创作当前主题的内容，不复制作者署名或水印。

### 5. 检查预览

读 [渲染经验](references/rendering.md)，创建本地工程。先制作约 10 秒开头 MP4，使用真实字幕、图解和拟用音乐。用户指定同款配乐且给出本地参考时，提取原音轨并记录来源，确认没有真人说话声后使用；不能生成相似音乐再称为原配乐。

从编码后的视频解码首帧、字幕出现、动作中段、转场和末帧，修复黑屏、裁切、溢出和闪跳，并试听音乐。提交实际预览。用户要求先看样片再决定时等待反馈；已授权直接完成全片时继续制作，不增加确认环节。更新 `制作状态.md`，明确预览与全片的完成情况。

### 6. 直出全片

扩展完整时间线，按反馈调整。默认导出 H.264 MP4 与 AAC 音轨。核对分辨率、帧率、时长、音轨，解码全片各镜头和结尾，试听音乐剪辑与循环接点。参数检查不能代替画面检查和试听。交付成片绝对路径、源码、分镜和配乐来源。发布、投稿或发消息只有用户要求时执行。

## 媒体助手

`scripts/media.py` 使用 Python 标准库及 FFmpeg/FFprobe，默认在 PATH 查找；也可传 `--tools-dir <工程/node_modules>`。路径按当前 shell 正确引用。

```text
python <skill>/scripts/media.py --tools-dir <工程/node_modules> probe <参考.mp4>
python <skill>/scripts/media.py --tools-dir <工程/node_modules> contact <参考.mp4> --output <联系表.jpg>
python <skill>/scripts/media.py --tools-dir <工程/node_modules> audio <参考.mp4> --output <音乐.wav>
python <skill>/scripts/media.py --tools-dir <工程/node_modules> check <成片.mp4> --width 1920 --height 1080 --fps 30 --duration 10 --require-audio
```

输出存在时拒绝覆盖；需要更新该产物时加 `--overwrite`。音轨提取不会去除说话声。联系表是取样分析，不能代替连续观看和试听。
