# 视觉叙事

分析参考的开头、解释段、转折和结尾，记录画幅、节奏、字体、配色、字幕位置、图解与音乐变化。同一作者的作品可能包含黑金、深蓝、卡通和暖色三维场景，不以单一封面判断全部风格。

用户选择黑金方向时，可使用近黑底、暖金标题、米白正文、宋体层次、细线与底部短句，红色表示风险，青灰表示另一组变量。保留边缘安全区与年份或来源角标。配色只是形式，核心是画面能解释知识。

图解按主题设计：匹配算法用连线、交通悖论用道路、概率用分布、奖励机制用反馈回路。例如“隔着屏幕认出机器”，展示提问者、未知参与者 A/B、问题发出与回答返回，而不只展示机器人和圆环。

信息按理解顺序出现：问题 → 参与者 → 过程 → 结果。流动点和箭头要明确代表什么，A/B 对照必须可辨认。音乐重拍配合标题或转场，过程动画留足读字幕时间。字幕和文字讲解始终保留；没有真人说话声不代表取消讲解。

验收实际成片：首帧、文字出现前后、动作中段、转场和末帧；检查字体加载、文字可读、边角标记、机制方向、日期和因果。连续观看判断节奏，试听判断配乐版本、说话声及接点。已有用户接受的样式和音乐继续沿用，按具体反馈修改。
